# 0034 — Ship the server, web/PWA, and remote MCP

Date: 2026-09-20

Status: accepted

## Context and problem

A durable server gives browsers, installed PWAs and AI connectors one consistent vault.

## Decision outcome

Release the API/worker, web/PWA and remote MCP as the supported product. Hostnames and providers are configurable, and the license is Apache-2.0.

## Consequences

One-time disclosure uses exact-text preview, selected-memory approval, denial and client-bound retrieval with expiry and revalidation. Native desktop hosting/pairing is outside the supported architecture.
